# TPI - Análisis de Datos

Trabajo Práctico Integrador de la materia **Análisis de Datos Inicial** (Tecnicatura Universitaria en Programación).

El objetivo del trabajo es construir un sistema de análisis y visualización sobre datos académicos, identificar factores de riesgo y proponer mejoras justificadas en evidencia.

## Cómo correr

1. Clonar el repositorio.
2. Crear y activar un entorno virtual (opcional pero recomendado).
3. Instalar dependencias: `pip install -r requirements.txt`.
4. Abrir el notebook con Jupyter o subirlo a Google Colab.
